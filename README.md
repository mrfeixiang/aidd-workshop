## 🇨🇳 中文

### 这是什么

一条**项目驱动**的 CADD / AIDD 学习路径，从 **Level 0 破零** 到 **Level 4
精通**，共 **5 个关卡、16 个真实 GitHub 项目**。专为制药研究者、药物化学、

3. **提 PR** —— 按 issue 清单补代码、加实验、写 report
4. **拿徽章** —— PR 合并后在你的 AIDD portfolio 里 +1

## 🇬🇧 English

### What is this

A **project-based learning path** for CADD / AIDD researchers, from **Level 0
(Starter)** to **Level 4 (Maestro)** — **5 levels · 16 real GitHub projects**.
Designed for pharma scientists, medicinal and computational chemists, and
AI-for-Science learners who want to go from "watching tutorials" to
**shipping code with their own name on it**.

No video course. No slide decks. No "Next" button. You fork a project, set up
the environment, run the code, fix bugs, and open a pull request — every
completed level leaves behind **clone-able evidence that you did the work**.

### The four-step learning loop

1. **Fork** this repo into your GitHub account.
2. **Clone & run** — follow the project README to install and reproduce.
3. **Submit a PR** — work through the issue checklist, add experiments, write the report.
4. **Earn a badge** — once merged, the project gets added to your AIDD portfolio.

## 🇰🇷 한국어

### 이 프로젝트는 무엇인가요

CADD / AIDD 연구자를 위한 **프로젝트 기반 학습 경로**입니다. **Level 0
(Starter)** 부터 **Level 4 (Maestro)** 까지, 총 **5개 레벨 · 16개의 실제
GitHub 프로젝트**로 구성되어 있습니다. 제약 연구자, 의약화학·계산화학
전공자, 그리고 AI-for-Science 분야에 입문하려는 학습자를 위해 설계되었습니다.

동영상 강의도, 슬라이드 덱도, "다음" 버튼에 끌려가는 방식도 아닙니다.
프로젝트를 **포크(fork)** 하고, 환경을 구성하고, 코드를 실행하고, 버그를
고치고, **풀 리퀘스트(PR)** 를 보냅니다 — 레벨을 통과할 때마다 **남이
clone 할 수 있는 형태의 증거**가 쌓입니다.

### 네 단계 학습 루프

1. **Fork** — 이 저장소를 본인 GitHub 계정으로 포크
2. **Clone & 실행** — 프로젝트 README 를 따라 환경을 만들고 결과를 재현
3. **PR 제출** — issue 체크리스트대로 코드 추가, 실험, 리포트 작성
4. **배지 획득** — PR 이 머지되면 개인 AIDD 포트폴리오에 프로젝트가 추가됨

### 5개 레벨

| 레벨 | 이름 | 기간 | 프로젝트 |
|------|------|------|----------|
| **L0** | Starter | 1–2주차 | [`hello-molecule`](./projects/hello-molecule), [`git-drug-lab`](./projects/git-drug-lab), [`aidd-env-starter`](./projects/aidd-env-starter) |
| **L1** | Apprentice | 3–5주차 | [`chembl-data-explorer`](./projects/chembl-data-explorer), [`qsar-from-scratch`](./projects/qsar-from-scratch), [`similarity-search-cli`](./projects/similarity-search-cli) |
| **L2** | Practitioner | 6–9주차 | [`pocket-finder`](./projects/pocket-finder), [`vina-pipeline`](./projects/vina-pipeline), [`virtual-screening-mini`](./projects/virtual-screening-mini) |
| **L3** | Craftsman | 10–14주차 | [`gnn-solubility`](./projects/gnn-solubility), [`transformer-reaction`](./projects/transformer-reaction), [`active-learning-lab`](./projects/active-learning-lab) |
| **L4** | Maestro | 15–24주차 | [`de-novo-generator`](./projects/de-novo-generator), [`alphafold-pipeline`](./projects/alphafold-pipeline), [`fep-workshop`](./projects/fep-workshop), [`aidd-portfolio`](./projects/aidd-portfolio) |

### 여섯 가지 역량 기둥

**화학정보학 · 구조생물학 · 머신러닝 · 생성 모델 · 엔지니어링 · 과학 커뮤니케이션**
