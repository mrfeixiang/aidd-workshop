# aidd-portfolio · 个人 AIDD Portfolio

> 毕业作品 · 出师一战 —— 把你做过的一切整合成一张对外名片。

**Level**: L4 · 精通 / Maestro
**Difficulty**: ★★★★☆
**预估工时**: 16h
**类型**: 阶段作品

---

## 这个项目在教什么

一个 AIDD 研究者的**产品力**不只在代码，也在"别人能多快找到你做的东西"。
这一关把 15 个项目的成果整合成一个**个人主页 + 6 个 pinned repos** 的 portfolio。

## 你会学到什么

- GitHub Pages / MkDocs / Quarto 的选型
- 技术博客的写作套路（problem → approach → result → pitfalls）
- Canonical URL、SEO、Open Graph 元数据
- 开源社区运营入门（issue templates、CONTRIBUTING.md）

## 环境准备

- 完成 L4 其他所有项目（这是毕业作品）
- 选好 portfolio 框架：[MkDocs Material](https://github.com/squidfunk/mkdocs-material) 或 [Quarto](https://quarto.org/)

## 任务清单

- [ ] 开一个 `<你的用户名>.github.io` 仓库
- [ ] 搭 MkDocs 站点，包含：
  - [ ] Landing：一段自我介绍 + 最自豪的一项工作
  - [ ] Projects：把 16 个项目按 L0–L4 分组陈列
  - [ ] Blog：为 3 个最硬核的项目各写一篇 blog
  - [ ] About / CV / Contact
- [ ] 在 GitHub profile 里 pin 6 个最能代表你的 repo
- [ ] 写一份 `README.md`（profile repo），包含：
  - [ ] 简短 intro
  - [ ] 正在做什么
  - [ ] 怎么联系你
  - [ ] GitHub stats / metrics badges
- [ ] 把 portfolio 挂到自定义域名（可选）
- [ ] 在 LinkedIn / Twitter / 小红书 发第一条动态宣传

## 交付物

`username.github.io` 上线 + 6 个 pinned repos + profile README + 至少 3 篇 blog。

- 站点能被搜索引擎索引
- 每个 pinned repo 有完整 README、License、CI 徽章
